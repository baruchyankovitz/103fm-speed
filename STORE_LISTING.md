## Privacy practices tab

**Single purpose**:

```
Lets users control the playback speed of recorded radio shows on Israeli radio websites (103FM, Galei Tzahal, Kan) through an improved audio player.
```

**Permission justification — storage**:

```
Saves the user's chosen playback speed so it is applied again on the next visit.
```

**Permission justification — host permissions**:

```
The extension only runs on 103fm.maariv.co.il, glz.co.il and kan.org.il, where it adjusts the playback speed of the site's audio player and shows a replacement player. No data is collected or sent anywhere.
```

**Are you using remote code?** No.

**Data usage**: do not tick any data type. Tick all three certifications (not sold to third parties, not used for unrelated purposes, not used for creditworthiness).
